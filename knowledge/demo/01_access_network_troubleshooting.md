# 接入网故障定位（公开模拟知识）

## 1. 故障信息收集
记录终端地址、故障现象、发生时间、是否全部中断以及是否近期变更过接入位置。单一现象不能直接作为根因。

## 2. 从终端信息定位资源
典型排查可按“终端信息 → 资源记录 → 接入设备 → 端口 → 实时证据”的顺序进行。公开示例只使用虚构设备和模拟数据。

## 3. 资源记录与实时证据交叉核验
资源记录反映登记关系，设备查询结果反映当前状态。应核对设备、端口、接口状态、MAC 学习和 VLAN 是否一致。

## 4. 常见故障判断
### 接口 DOWN
优先检查终端、电源、网卡、线缆和实际接入位置，不能直接认定交换机故障。

### 接口 UP 但无目标 MAC
继续检查终端是否产生流量、MAC 是否正确、实际端口以及 VLAN。

### VLAN 不一致
记录登记 VLAN 与当前证据差异，并交由授权人员核查；辅助系统不自动修改配置。

### 接入侧正常但业务异常
若接口、MAC、VLAN 等证据正常，继续检查网关、DNS、上层路由、访问策略或业务系统。

## 5. 推荐诊断顺序
资源关系 → 实际设备 → 实际端口 → Interface → MAC → VLAN → ARP → 终端地址 → 上层业务。
