# 接入网络基础（公开模拟知识）

## 1. LAN、MAN、WAN
LAN、MAN、WAN 分别用于描述不同覆盖范围的网络。

## 2. 常见设备角色
接入交换机负责终端接入，汇聚和路由设备负责进一步转发。实际拓扑应以资源数据为准。

## 3. PON 接入
PON 是常见光接入技术，本 Demo 不处理真实 OLT/ONU 配置，仅作为背景知识。

## 4. 交换机接入
交换机接入排障通常关注用户侧设备、交换机端口、接口状态、MAC、VLAN、上联以及终端 IP 和网关。

## 5. 二层与三层基本概念
二层常见证据包括 MAC、VLAN 和端口；三层常见证据包括 IP、网关、ARP 和路由。
