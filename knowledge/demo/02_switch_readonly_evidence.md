# 交换机只读证据（公开模拟知识）

## 1. Interface 状态
接口 UP 表示物理链路具备基本连接条件，但不代表业务一定正常。接口 DOWN 时优先核查终端和物理连接。错误计数持续增长可能提示链路质量问题。

## 2. MAC 地址表
MAC 表可用于判断目标终端是否被交换机学习、学习在哪个端口以及所属 VLAN。接口 UP 但无目标 MAC 时应继续核查终端流量、实际端口和 VLAN。

## 3. ARP 表
ARP 用于核对 IP 与 MAC 的三层邻接关系。MAC 存在但 ARP 缺失不等于故障已确定，可能还需要结合通信时间、表项老化和查询位置判断。

## 4. VLAN 证据
比较资源登记 VLAN、接口 VLAN 和 MAC 学习 VLAN。发现不一致时只记录证据并升级人工确认，不自动下发修改命令。

## 5. 证据优先级
建议综合资源记录、接口状态、MAC、VLAN、ARP 和终端配置进行判断，避免依赖单一字段。

## 6. 只读安全边界
公开 Demo 仅做查询、解析、诊断和知识检索，不执行 VLAN 修改、端口启停、设备重启或配置保存。
