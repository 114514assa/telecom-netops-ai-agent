# 故障处理原则（公开模拟知识）

## 1. 故障处理基本原则
先明确影响范围，再收集证据、缩小范围、形成建议并人工确认。高风险操作不由 Agent 自动执行。

## 2. 标准故障定位方法
可按终端侧、物理链路、二层接入、VLAN、三层地址、上层路由、DNS 和业务系统逐层定位。

## 3. 常见设备和链路问题
常见线索包括掉电、线缆异常、错误计数增长、丢包、拥塞或模块异常。只有存在对应证据时才能提高相关判断置信度。

## 4. 时延和丢包问题
若出现持续丢包、时延升高或接口错误计数增长，应继续核查链路质量和容量情况，不能只凭一次探测直接确定根因。

## 5. 故障升级
需要生产配置修改、硬件更换、设备重启或影响范围扩大时，应升级给授权维护人员。

## 6. 复测与闭环
处理后复测接口、MAC、VLAN、ARP、网关、DNS 和目标业务，并记录关键证据。
