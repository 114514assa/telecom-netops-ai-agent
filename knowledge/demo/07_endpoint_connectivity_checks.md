# 终端连通性核查（公开模拟知识）

## 1. Windows 网络信息
可通过 ipconfig、route print 等只读命令查看地址、网关、DNS 和路由信息。

## 2. 默认网关测试
网关可达说明本地到三层网关具备基本可达性；网关不可达时需结合地址、VLAN、ARP 和链路状态判断。

## 3. DNS 测试
若 IP 可达但域名不可用，应重点检查 DNS 配置或 DNS 服务。

## 4. 路径测试
tracert 可辅助观察路径，但中间节点不回应探测报文不一定代表故障。

## 5. 地址调整后的检查顺序
IP/掩码/网关/DNS → 网关连通 → 域名解析 → 业务访问 → 与交换机 Interface/MAC/VLAN/ARP 证据交叉核对。

## 6. 典型场景
### 地址与网关不匹配
地址调整后仍使用旧网关，可能造成网络不可达。

### DNS 配置异常
可能表现为网关和 IP 访问正常，但域名解析失败。

### 接入侧正常、业务仍失败
若 Interface、MAC、VLAN、网关均正常，应继续检查 DNS、路由、访问策略或业务系统。
