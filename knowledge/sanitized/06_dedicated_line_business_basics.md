# 专线与云网业务基础

## 1. 互联网专线

互联网专线通常用于：

- 固定公网地址需求
- 企业网站或系统访问
- 稳定互联网接入
- 对时延、稳定性有更高要求的业务

排障时常检查：

- IP、掩码、网关、DNS
- 用户侧路由器或交换机
- 接入设备
- 上层互联网路径
- 业务端口与访问策略

## 2. 组网专线

组网专线用于不同办公点或业务点之间的内部网络互通，一般不等同于互联网出口。

常见形式包括：

- 二层 VPN
- 三层 VPN
- 专用承载网络
- 光传输类专线

### 二层 VPN

运营侧主要提供二层传输通道，客户侧自行规划 IP。

### 三层 VPN

运营网络参与三层地址和路由，需要同时核对：

- 用户地址
- 网关
- 路由
- 接入 VLAN
- 对端网络

## 3. PON 类专线与交换机类专线

PON 接入常涉及：

- OLT
- ONU/ONT
- 业务通道
- 用户固定地址
- 用户侧设备

交换机接入常涉及：

- 接入交换机
- 用户端口
- VLAN
- 上联网络
- 用户侧路由器

## 4. 常见问题

### 固定地址设置错误

表现：

- 物理连接正常
- 用户无法访问业务或互联网

核查：

- IP
- 掩码
- 网关
- DNS
- 地址是否属于当前业务

### 用户侧设备异常

可通过逐级隔离的方法判断：

用户终端  
→ 用户侧交换/路由设备  
→ 接入设备  
→ 上层网络

Agent 只提供核查顺序，不自动修改用户或运营设备配置。

### 速率异常

核查方向：

- 用户侧链路
- 接入设备端口
- 上联带宽
- 历史流量
- 是否存在拥塞
- 业务配置是否与合同/资源记录一致

## 5. 云专线

云专线用于本地网络与云资源之间的连接。

出现异常时除接入侧外，还可能需要核查：

- 云侧网络
- 路由
- 安全策略
- 云资源状态
- 跨域网络路径
