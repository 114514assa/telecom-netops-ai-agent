# 云网与接入基础（脱敏摘要）

## 城域网设备角色

核心路由器承担城域出口与核心转发；业务/汇聚路由设备承担业务汇聚；MSE 是多业务边缘路由器；OLT 服务于 PON 接入；交换机既可汇聚接入设备，也可通过光电方式直接承载用户业务。资源系统登记关系不能代替设备实时状态核查。

## PON 与交换机接入

PON 是 OLT、ODN 与 ONU/ONT 组成的点到多点接入方式；交换机接入通常为用户提供相对独享的光纤/端口资源。当前项目只处理交换机接入终端的模拟故障，不覆盖光猫注册、OLT 配置和真实专线开通流程。

## IP、网关和 DNS

IPv4 地址由网络部分和主机部分组成。终端配置核查至少包括 IP、掩码、默认网关、DNS 和 MAC。默认网关决定非本地网段流量的下一跳，DNS 异常可能表现为 IP 可达但域名业务不可用。

## 网络域与隔离

生产维护网络与办公网络应根据用途和权限进行隔离。地址调整不能只修改终端 IP，还需要核对目标网段、网关、DNS、接入 VLAN、业务依赖及变更后的连通性。
